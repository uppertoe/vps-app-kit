# Security

Please report a vulnerability through GitHub's private reporting on this
repository (Security, then Report a vulnerability), not in a public issue.

The kit is the shared security layer for every app made from
[vps-app-template](https://github.com/uppertoe/vps-app-template), so a report
is treated as urgent. A release that changes a security default says so in its
notes, under the heading "Security defaults".
